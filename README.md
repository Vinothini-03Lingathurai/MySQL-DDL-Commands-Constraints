# MySQL-DDL-Commands & Constraints

📌 Project Overview

This project demonstrates the use of MySQL DDL (Data Definition Language) commands and constraints by creating and managing an Employee Database.

The project includes the creation of Department, Location, and Employees tables and demonstrates various database operations such as table creation, alteration, renaming, truncation, and dropping.

🎯 Objective

The main objective of this project is to:

Create an Employee database using MySQL.
Create tables based on the given database schema.
Understand and implement DDL commands.
Modify existing table structures.
Apply different SQL constraints.
Establish relationships between tables using Foreign Keys.
Understand how TRUNCATE and DROP affect database objects.

📚 Key Learning Outcomes

Through this project, I gained practical understanding of:

MySQL database creation and management.
DDL commands.
Table structure modification.
SQL constraints.
Primary and Foreign Key relationships.
Data integrity and validation.
Difference between TRUNCATE and DROP.
Database and table naming/renaming operations.

💻 Tools & Technologies
Database: MySQL
SQL Client: MySQL Workbench
Language: SQL
Concepts: DDL Commands & Constraints

⭐ Conclusion

This project provides hands-on experience with MySQL DDL commands and database constraints. It demonstrates how database structures can be created, modified, renamed, truncated, and deleted while maintaining data integrity through appropriate constraints.
